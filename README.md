# Iv Production – Webová Prezentace 🎥✨

Profesionální, moderní a dynamická webová prezentace pro video produkci **Iv Production**. Web slouží jako portfolio, informační hub a hlavní nástroj pro získávání klientů (svatby, plesy, firemní akce).

## 🚀 Co web umí a jaké má funkce

Tento web je navržen s důrazem na **vizuální zážitek**, rychlost a prémiový vzhled.

### Hlavní funkce:
*   **Responsivní Design**: Plně optimalizováno pro mobily, tablety i desktopy.
    *   *Novinka:* **Hamburger menu** s „glassmorphism“ efektem a animacemi pro mobilní zařízení.
*   **Dynamické Prvky**:
    *   **Hero Sekce**: Video/obrázkové pozadí s overlay efektem a call-to-action tlačítky.
    *   **Partneři Slider**: Nekonečný, automaticky posuvný pás log partnerů. Loga jsou ve výchozím stavu čistá (bílá/šedá) a po najetí myší se karta změní na zlatou s černým logem (efekt šipky).
    *   **Počítadla**: Animovaná čísla ve statistikách (500+ akcí atd.), která se načítají při scrollování.
*   **Interaktivní Galerie**:
    *   **Lightbox**: Možnost rozkliknout fotografie a videa do celoobrazovkového režimu.
    *   **Hover Efekty**: Karty služeb a portfolia mají moderní 3D efekty při najetí myší.
*   **Estetika**:
    *   Temný režim (Dark Theme) s prvky **zlata** (#C9A227) pro luxusní dojem.
    *   Využití **Glassmorphismu** (efekt matného skla) v hlavičce a mobilním menu.
    *   Moderní typografie (font **Outfit**).

## 🛠️ Použité Technologie

*   **HTML5** – Sémantická struktura (SEO friendly).
*   **CSS3** – Moderní stylování (Flexbox, Grid, CSS Variables, Animations).
*   **JavaScript (Vanilla)** – Logika pro slider, mobilní menu, modální okna a animace.
*   **Font Awesome / SVG** – Ikony a grafické prvky.
